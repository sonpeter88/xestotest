# MyApp

A simple iOS application created with Xcode.

## Requirements

- Xcode 15.3 or later
- iOS 14.0 or later
- Swift 5.0 or later

## Building

1. Open `MyApp.xcodeproj` in Xcode
2. Select the target device or simulator
3. Press Cmd+B to build or Cmd+R to build and run

## Project Structure

- `MyApp/AppDelegate.swift` - Application delegate
- `MyApp/SceneDelegate.swift` - Scene delegate for iOS 13+
- `MyApp/ViewController.swift` - Main view controller
- `MyApp/LaunchScreen.storyboard` - Launch screen
- `MyApp/Info.plist` - Application configuration
